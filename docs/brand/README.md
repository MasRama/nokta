# Nokta's logo

The wordmark is "nokta" in Sora Bold, ending on its own period stretched
into an ember capsule: the island the notch opens from. Smaller sizes drop
letters and keep the island.

| Size | File |
| --- | --- |
| Full logo, light ground | `nokta-logo.svg` |
| Full logo, dark ground | `nokta-logo-reverse.svg` |
| One color | `nokta-logo-mono-black.svg`, `nokta-logo-mono-white.svg` |
| Inside an interface (no clear space) | `nokta-wordmark.svg`, `nokta-wordmark-reverse.svg` |
| App icon, avatar | `nokta-icon.svg` (`nokta-icon.png`, 1024 px), `nokta-icon-light.svg` |
| 32 px and under, favicon | `nokta-favicon.svg` |
| Symbolic icon (GNOME, 16 px) | `nokta-symbolic.svg` |
| Social preview (1280 x 640) | `nokta-social.png` |

Every file is outlined paths: no font needs to be installed.

## Colors

| Name | Hex |
| --- | --- |
| Ink | `#0a0a0c` |
| Ember | `#ff6a3d` |
| Paper | `#f5f5f7` |
| Graphite | `#8e8e93` |

The island is ember on ink or paper, and the letters' color everywhere else.

## Use

- Keep clear space of the island's height on every side; the `nokta-logo`
  files already include it.
- Show the full logo at least 80 px wide; below that, use the icon.
- Do not recolor the letters ember, stretch the logo, or set the name in
  another font next to it.
