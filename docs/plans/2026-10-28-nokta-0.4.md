# Nokta 0.4 Implementation Plan

**Spec:** `docs/specs/2026-10-28-nokta-0.4-design.md`

**Global constraints:** contracts first, tests first, heavy commands one at a time, one branch and pull request per part, GNOME 46 to 51 CI green before merging.

## Part 1: Lyrics for browser tracks (`feat/lyrics-browsers`)

- [ ] `clean.rs` tests (YouTube titles, channels, dashes, feat., Indonesian examples), then the code.
- [ ] `lrclib.rs`: candidates in order, stricter search match; wiremock tests.
- [ ] `xesam:url` on `Track`; local `.lrc` next to the file and in the lyrics folder (`Paths::data_dir`); tests.
- [ ] Cache key version.
- [ ] Commits: `fix(lyrics): find lyrics for songs played on YouTube in a browser`, `feat(lyrics): read lyrics from local .lrc files`.

## Part 2: Players (`feat/players`)

- [ ] `Media1.xml`: `Players`, `SelectPlayer`; contract test; `contracts.ts`.
- [ ] Selector `select(name)` tests, watcher, D-Bus; service test.
- [ ] Extension: player row in the expanded view, arrows, scroll; logic tests; devshell with two fake players.
- [ ] Commit `feat(media): switch between players from the notch`.

## Part 3: Focus mode (`feat/focus-mode`)

- [ ] Config keys and validation; timer logic for sessions and long breaks; `Timer1` additions; tests.
- [ ] Extension: quiet notifications with restore; GSettings schema and keybinding; settings rows; logic tests.
- [ ] Commits per side: `feat(timer): take a long break after four sessions`, `feat(timer): silence notification banners while focusing`, `feat(timer): start and stop focus with a shortcut`.

## Part 4: Privacy dots (`feat/privacy-dots`)

- [ ] Logic for which dots show; sources with feature checks; notch dot; setting; smoke check on every version that the hooks are found.
- [ ] Commit `feat(extension): show privacy dots for the camera, microphone and screen sharing`.

## Part 5: Notifications (`feat/notifications`)

- [ ] `[notifications]` config; logic for what to take over; hook with a check; notch view; click and hover; `disable()` restores.
- [ ] Smoke check: a `Notify` call shows in the notch on GNOME 46 to 51.
- [ ] Commit `feat(notifications): show notifications in the notch`.
