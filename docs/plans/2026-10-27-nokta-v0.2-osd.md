# Nokta v0.2 OSD Implementation Plan

**Goal:** Show volume, brightness, other GNOME OSD and Caps Lock changes in the notch instead of GNOME's popup.

**Spec:** `docs/specs/2026-10-27-nokta-v0.2-osd-design.md`

**Architecture:** Extension-only feature `extension/src/features/osd/`. The daemon only publishes four new config keys in the existing `Appearance` and `Behavior` tables; the D-Bus contract does not change. `extension.ts` draws the OSD as a temporary mode over the unchanged `NotchMachine`.

## Global constraints

- GNOME Shell 46 only. No polling, no new timers except the OSD hide timer while the OSD is shown.
- Everything `enable()` creates (method replacements, keymap signal, actors, timers) is undone in `disable()`.
- Decisions go in `logic/` modules with Node tests. Tests first.
- Heavy commands one at a time.
- Defaults: `osd_width 300`, `replace_osd true`, `osd_duration_ms 1500`, `show_caps_lock true`.
