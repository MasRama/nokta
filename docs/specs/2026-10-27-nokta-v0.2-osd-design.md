# Nokta v0.2 design: OSD in the notch

Status: approved
Date: 2026-10-27
Scope: GNOME Shell 46. Builds on the v0.1 design
(`2026-10-27-nokta-v0.1-design.md`); everything not named here is unchanged.

## 1. Goal

When the volume, the screen brightness or another system level changes, the
notch widens for a moment and shows an icon, a level bar and the percentage.
GNOME's own popup at the bottom of the screen no longer appears. Turning Caps
Lock on or off shows the same kind of message, which GNOME does not show at
all today.

### Success criteria

1. Volume keys, brightness keys, keyboard backlight, mic mute, touchpad and
   airplane mode toggles all show in the notch, never in GNOME's popup, while
   the notch is on screen.
2. Pressing a key repeatedly updates the bar in place: the notch does not
   shrink and widen again between presses.
3. When the notch is hidden (a fullscreen app) or the screen is locked,
   GNOME's popup is shown as before, so feedback is never lost.
4. `replace_osd = false` gives back GNOME's popup at once, without a restart.
5. No new timers while nothing changes: the only timer is the one that hides
   the OSD, and it exists only while the OSD is shown.

## 2. Where it lives

The feature is extension-only. Every OSD in GNOME Shell 46 goes through one
function, `Main.osdWindowManager.show(monitorIndex, icon, label, level,
maxLevel)`:

- `ui/status/volume.js` calls it for volume changes from the top bar.
- `ui/shellDBus.js` calls it for `org.gnome.Shell.ShowOSD`, which
  gnome-settings-daemon uses for volume keys, brightness, keyboard backlight,
  mic mute, touchpad and airplane mode.
- `ui/windowManager.js` calls it for a few window-manager messages.

Caps Lock comes from the Clutter keymap's `state-changed` signal. Neither
source needs the daemon, a network, files or polling, so `noktad` gains no
feature. It only publishes four new config keys (section 5). The D-Bus
contract does not change: `Appearance` and `Behavior` are `a{sv}` tables, and
the extension already falls back to defaults for missing keys.

New extension feature folder `extension/src/features/osd/`:

| File | Purpose |
|---|---|
| `index.ts` | Public boundary |
| `hook.ts` | Replaces `osdWindowManager.show` and `hideAll`, restores them |
| `capslock.ts` | Follows the Caps Lock state of the keymap |
| `view.ts` | The OSD row: icon, bar, text |
| `logic/content.ts` | What to show for a request (pure) |
| `logic/timer.ts` | When the OSD shows and hides (pure) |

`osd` depends on no other feature.

## 3. Behavior

### 3.1 Taking over the OSD

- With `replace_osd = true` the extension replaces the `show` and `hideAll`
  methods on the `Main.osdWindowManager` instance. `disable()`, or
  `replace_osd` turning false, removes the replacements. If something else
  has replaced the method on top of Nokta's in the meantime, Nokta leaves it
  alone and logs one message.
- A request goes to the notch when the notch is visible and the session is
  not locked. Otherwise it goes to GNOME's original `show`, unchanged.
- The monitor index in the request is ignored: there is one notch, on the
  primary monitor (multi-monitor is a later release).
- `hideAll()` calls GNOME's original and also hides the notch OSD at once.

### 3.2 What is shown

From a request `{ icon, label, level, maxLevel }` (`level` and `label` may be
null, `maxLevel` defaults to 1):

| Request | Bar | Text |
|---|---|---|
| `level` set | `level / maxLevel`, clamped to 0…1 | `round(level × 100)` + `%` (volume above 100 % shows e.g. `120%`) |
| no `level`, `label` set | hidden | the label |
| neither | hidden | empty |

The icon is the request's `Gio.Icon`, 16 px, in the foreground color. A
missing icon leaves the icon slot empty.

Caps Lock shows the icon `input-keyboard-symbolic` with the text
`Caps Lock on` or `Caps Lock off` and no bar. It is shown only on a change of
the Caps Lock state, never at startup, and only when `show_caps_lock = true`.
It does not depend on `replace_osd`.

### 3.3 Notch states

The OSD is a temporary mode drawn over the v0.1 state machine (idle,
collapsed, expanded), which keeps running underneath unchanged.

- Showing: the notch resizes to `osd_width` × `height` and the OSD row fades
  in. The resize uses the `width` animation from idle or collapsed and the
  `close` animation from expanded.
- A new request while the OSD is shown updates the row in place and restarts
  the hide timer. The bar eases to the new value (100 ms × animation_speed).
- After `osd_duration_ms` without a new request the notch returns to the
  mode the state machine is in at that moment (it may have changed meanwhile,
  e.g. music started), with the usual animation for that move.
- While the OSD is shown, mode changes of the state machine are remembered
  but not drawn. Hover keeps working: resting on the notch during the OSD
  makes it open once the OSD ends.
- The music timers (progress, lyrics) follow the drawn mode, so they stop
  while the OSD covers an expanded notch.

### 3.4 Layout

One row, `height` high, `osd_width` wide, vertically centered:
icon (16 px) — 10 px — bar (4 px high, fills the remaining width, rounded,
track in foreground at 25 % alpha, fill in foreground) — 10 px — text
(12 px, tabular figures, right-aligned, at least 36 px wide). Padding
0 14 px. When the bar is hidden the text takes the free space, left-aligned.

## 4. Error handling

| Situation | Behavior |
|---|---|
| Daemon not running | Defaults apply (`replace_osd = true`), so the OSD still works |
| Another extension replaced `show` after Nokta | Nokta does not restore over it; it logs once |
| Notch hidden by a fullscreen app, or screen locked | GNOME's popup is used |
| Icon fails to load | Empty icon slot, the rest still shows |

## 5. Config

New keys, published in the existing tables:

```toml
[appearance]
osd_width = 300          # notch width while it shows volume, brightness or Caps Lock

[behavior]
replace_osd = true       # show volume, brightness and other OSD in the notch instead of GNOME's popup
osd_duration_ms = 1500   # how long the notch shows the OSD after the last change
show_caps_lock = true    # show a message in the notch when Caps Lock turns on or off
```

## 6. Testing

- Daemon (`cargo test`): the defaults and the `to_dbus` key lists include
  the new keys; the default file still parses to the defaults.
- Extension logic (`npm test`): `logic/content.ts` for every row of the table
  in 3.2; `logic/timer.ts` for show, restart on a new request, hide after the
  duration and hide on demand; settings parsing of the new keys.
- UI (devshell checklist in `docs/testing.md`): volume OSD from idle,
  collapsed and expanded; repeated requests; label-only request; Caps Lock
  on and off; `replace_osd = false`; GNOME's popup while a fullscreen window
  covers the notch.

## 7. Out of scope

The OSD on other monitors than the primary, a keyboard-layout indicator,
battery/Wi-Fi/headset alerts (their own spec), and custom icons per OSD kind.
